# OREVO Website

Official public website for **OREVO — Your time. Clearly.**

This repository contains only the static public website. The Flutter application source, signing keys, local configuration and private release material are maintained separately.

## Structure
- `index.html` — product landing page
- `privacy.html` — privacy policy
- `install.html` — Android Early Access installation guide
- `css/style.css` — responsive design system
- `js/main.js` — language/theme/reveal interactions
- `assets/` — public web assets

## Deployment
Designed for GitHub Pages from the `main` branch.
